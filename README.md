# ServerManager

## 01 CMakelists.txt 빌드 명령어
```build_cmd
mkdir build && cd build # 1. 빌드 폴더 생성 및 이동
cmake ..                # 2. 크로스 플랫폼 빌드 환경 구성
cmake --build .         # 3. 컴파일 및 빌드 수행
```
